## Project Overview
This project simulates a small healthcare network infrastructure using Cisco Packet Tracer.

## Devices Used
- Cisco 2811 Router
- Cisco 2960 Switches
- PCs representing MRI, CT, PACS, Doctor, Reception

## Features
- VLAN segmentation
- DHCP configuration
- Inter-department communication
- Basic hospital network design

## Verification
Successful ping tests between network devices were completed.
